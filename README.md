# Spectra development documentation pack

This is an editable project specification, not application code or installed Claude skills. It adapts the supplied Universal Master Prompt V2.0 (20 pages) and the confirmed conversation requirements. All implementation choices are proposed until reviewed; no provider accounts, API scopes, internal source APIs, pricing, assets, infrastructure or live integrations were verified in this document preparation.

## Start here
1. Extract the ZIP into the new or existing project repository (inspect existing files first; do not overwrite an existing CLAUDE.md without merging/review).
2. Open `PROJECT.yaml` and confirm owners, technology, brand, roles, budgets and outstanding discovery items.
3. Launch Claude Code from project root. Provide: `Read CLAUDE.md, MASTER_PROMPT.md, PROJECT.yaml and the referenced documents. Start Phase 0 discovery only; do not write application code or perform live actions. Report findings and request necessary approvals.`
4. Review phase 0 report and approve requirements/architecture/design before coding. Keep universal rules stable; edit project files as decisions change.
